# Diez Mundos

Cuarenta películas de animación 3D de 30 minutos. Formato 16:9, pensadas para YouTube. Las primeras diez siguen en la sala; se sumaron treinta más.

Cada pieza es animación pura, sin narrador. En este repo está la ficha de cada una: título, descripción y hashtags, lista para pegar al subir.

No hay masters MP4 de 4K aquí: media hora en 4K pesa varios gigabytes y GitHub no hospeda ese archivo. Las películas se ven en la sala Diez Mundos, en tiempo real, a la resolución de la pantalla. Las versiones HD de las primeras diez se publican como [releases](https://github.com/inodeman/diez-mundos/releases) cuando termina cada exportación.
